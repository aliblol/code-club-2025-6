📥 How to Use
  1. Find the latest session file

    Open the coin-collector/microbit classrom files folder. Look for the file with the most recent date in its name (e.g., arcade - microbit classroom session - 2026-06-03-2.html).

  2. Open the file in your browser

    Double-click the latest HTML file to open it in your default web browser.

  3. Click "Continue classroom session"

    This will open micro:bit Classroom and load your students' code from the last session.

  4. Work and save your updates

    Code and test. When done, click your name in micro:bit Classroom and select "Save my session" to download the updated file.

  5. Move the new file to the folder

    Save your downloaded session file to coin-collector/microbit classrom files folder with today's date in the name.
